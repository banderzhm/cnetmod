# HttpArena 第一名目标跟踪表

2026-11-09 复核结论：M1/M2 的同二进制 A/A 未达到 1% 精度。以下本地变化和排名外推
全部保留为历史记录，暂停用于认定当前名次，包括“本地预计第一”的结论。官方独立测试
值仍按原始来源保存。此前小幅回退实验也只能说明当轮观察结果，不能证明该方向普遍无效。
网络、睿频、预热和 SMT 掩码对照及原始数据位置见执行记录 M1/M2。

## 数据口径

2026-11-09 Q3 已保留 ACK 解码的所有权转移和分配边界检查，175 项相关测试通过。
局部基准的单附加范围耗时减少 9.77%，64 范围当轮增加 1.21%。端到端收益仍待确认，
因此本表的预计成绩维持原有口径。完整条件和原始数据目录见推进记录 Q3。

同日 Q4 保留 QPACK 原文解码和 HPACK 原文编码的批量复制。79 项单元测试通过，
4/8/16 worker 的 h2c、H2 TLS、H3 共 90,000 次请求成功，另有 WebSocket/gRPC 校验通过。
局部 codec 基准显示原文解码耗时减少 71%–95%，编码控制项仍有较大波动。
完整 HTTP 吞吐收益尚未确认，因此预计成绩继续维持原有口径。

Q6 修复了明文/TLS 缓存正文分块发送的正文失效及长度头冲突。16KiB chunked 诊断中，
4/8/16 worker 的配对中位吞吐分别提高约 61%/55%/28%，CPU/请求分别减少约 38%/36%/26%。
8、16 worker 已独立复跑，全部轮次保存在推进记录中。8 worker 的峰值 RSS 中位数增加约
4.3MiB，106 项测试、写入专项及跨协议检查通过。该场景的收益仅作内部诊断记录，
本表的榜单成绩和预测数值维持原有口径。
