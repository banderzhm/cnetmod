# HTTP/3 应用层开发手册

## 快速入门

HTTP/3 是构建在 QUIC 传输层之上的新一代 HTTP 协议，基于 RFC 9114 规范实现。本手册介绍如何使用 cnetmod HTTP/3 API 开发服务端和客户端应用。

### Server 示例

```cpp
#include <cnetmod/protocol/http/v3.hpp>
#include <cnetmod/ssl_context.hpp>
#include <cnetmod/io_context.hpp>
#include <cnetmod/http/router.hpp>

int main(int argc, char** argv) {
    // 1. 创建 IO 上下文
    auto ctx = cnetmod::make_io_context(4);  // 4 worker threads
    
    // 2. 配置 SSL 上下文（BoringSSL QUIC 模式）
    auto ssl_ctx = cnetmod::ssl_context::quic_server();
    ssl_ctx.load_cert_file("cert.pem");
    ssl_ctx.load_key_file("key.pem");
    ssl_ctx.set_alpn_protocols({"h3"});  // HTTP/3 必须声明 h3
    
    // 3. 配置路由
    auto router = std::make_unique<cnetmod::http::router>();
    
    router->get("/hello/:name", [](cnetmod::http::request_context& ctx) {
        auto name = ctx.params().get("name").value_or("World");
        ctx.response().set_status(200);
        ctx.response().body() = fmt::format("Hello, {}!", name);
    });
    
    router->get("/echo/*", [](cnetmod::http::request_context& ctx) {
        auto resp = ctx.response();
        resp.set_status(200);
        resp.set_header("Content-Type", "text/plain");
        resp.body() = std::string{ctx.request().body()};
    });
    
    // 4. 启动 HTTP/3 服务器
    auto server = cnetmod::http::v3::make_http3_server(*ctx, ssl_ctx, 4433, *router);
    cnetmod::spawn(*ctx, server->start());
    
    // 5. 等待关闭信号
    ctx->run();
    
    return 0;
}
```

**关键参数说明**：

```cpp
struct http3_server_options {

    size_t max_concurrent_streams = 100;  // 默认并发流上限

    duration max_connection_lifetime = std::chrono::hours(1);
```

### Client 示例

```cpp
#include <cnetmod/http/v3_client.hpp>
#include <cnetmod/ssl_context.hpp>
#include <iostream>

int main(int argc, char** argv) {
    auto ctx = cnetmod::make_io_context();
    auto ssl_ctx = cnetmod::ssl_context::quic_client();
    ssl_ctx.load_verify_locations("/etc/ssl/certs/ca-certificates.crt");
    ssl_ctx.set_alpn_protocols({"h3"});
    
    // 配置客户端
    cnetmod::http::v3::http3_client_options opts;
    opts.max_concurrent_streams = 100;
    opts.max_connection_lifetime = std::chrono::hours(1);
    
    auto client = cnetmod::http::v3::http3_client(*ctx, ssl_ctx, opts);
    
    // 建立连接
    auto conn_result = client.connect("localhost", 4433).sync_wait();
    if (!conn_result) {
        std::println("连接失败: {}", conn_result.error().message());
        return 1;
    }
    
    std::println("✓ 已连接到 server");
    
    // 构造 HTTP 请求
    auto req = cnetmod::http::v3::http3_request{};
    req.method = cnetmod::http::method::GET;
    req.path = "/echo/HelloWorld";
    req.set_header("User-Agent", "cnetmod/1.0");
    req.set_header("Accept", "application/json");
    
    // 发送请求并等待响应
    auto resp_result = client.send_request(req).sync_wait();
    if (!resp_result) {
        std::println("请求失败: {}", resp_result.error().message());
        return 1;
    }
    
    auto& resp = resp_result.value();
    std::println("Status: {}", resp.status());
    std::println("Headers:");
    for (auto [name, value] : resp.headers()) {
        std::println("  {}: {}", name, value);
    }
    std::println("Body: {}", std::string_view{resp.body()});
    
    // 优雅关闭连接
    client.close().sync_wait();
    
    return 0;
}
```

## QPACK 静态表完整索引

### RFC 9204 Appendix A 条目列表（前 20 项）

QPACK（QUIC 头部压缩）静态表包含 99 个预定义条目，以下为常用前 20 个：

| 索引 | Name | Value | 使用频率 |
|-----|------|-------|---------|
| 1 | `:authority` | `""` | 高（必须包含） |
| 2 | `:method` | `GET` | 高 |
| 3 | `:method` | `POST` | 中 |
| 4 | `:path` | `/` | 高 |
| 5 | `:path` | `/index.html` | 低 |
| 6 | `:scheme` | `http` | 中（重定向场景） |
| 7 | `:scheme` | `https` | 高（主流场景） |
| 8 | `:status` | `200` | 高 |
| 9 | `:status` | `204` | 低（No Content） |
| 10 | `:status` | `304` | 中（Not Modified） |
| 11 | `:status` | `404` | 中（Not Found） |
| 12 | `accept-encoding` | `gzip, deflate, br` | 高（压缩支持） |
| 13 | `content-length` | `0` | 中 |
| 14 | `content-type` | `application/json` | 高 |
| 15 | `content-type` | `text/html` | 高 |
| 16 | `date` | `*dynamic*` | 高（每次不同） |
| 17 | `expires` | `*dynamic*` | 低 |
| 18 | `last-modified` | `*dynamic*` | 中 |
| 19 | `user-agent` | `*dynamic*` | 高（每次不同） |
| 20 | `connection` | `close` | 低（HTTP/3 默认持久） |

### 使用方法

**Literal with Base Indexing**：

```cpp
// 编码非静态表的自定义头部
// 格式: [1-bit: literal flag] [7-bit: index] [variable: value length] [string]
cnetmod::qpack::encoded_header encode_literal_with_index(
    size_t index,
    std::string_view value) {
    
    std::vector<std::byte> buffer;
    buffer.push_back(std::byte{0x80 | (index & 0x7F)});  // 0x80 + 索引
    append_varint(buffer, value.size());
    std::transform(value.begin(), value.end(), 
                   std::back_inserter(buffer), 
                   [](char c) { return std::byte{c}; });
    return buffer;
}

// 示例：自定义 header "X-Request-ID: abc-123"
auto encoded = encode_literal_with_index(99, "abc-123");
```

**Literal Never Indexed**：

```cpp
// 敏感头部（如 Authorization），不进入动态表缓存
cnetmod::qpack::encoded_header encode_sensitive_header(
    std::string_view name,
    std::string_view value) {
    
    std::vector<std::byte> buffer;
    // 格式: 0x10 (literal never indexed) + name length + name + value length + value
    buffer.push_back(std::byte{0x10});
    append_varint(buffer, name.size());
    append_string(buffer, name);
    append_varint(buffer, value.size());
    append_string(buffer, value);
    
    return buffer;
}

// 使用场景
auto req = cnetmod::http::v3::http3_request{};
req.set_sensitive_header("Authorization", "Bearer secret_token_12345");
// 该头部将被标记为 Never Indexed，不参与 QPACK 压缩
```

## HTTP/3 Frame 类型速查表

| Type | Value | Description | Stream Usage |
|------|-------|-------------|--------------|
| `DATA` | 0x00 | HTTP 实体体数据 | 双向流 |
| `HEADERS` | 0x01 | 请求/响应头部（QPACK 编码） | 双向流 |
| `CANCEL_PUSH` | 0x03 | 客户端取消已承诺的推送 | 客户端控制流（Client→Server） |
| `SETTINGS` | 0x04 | 配置参数交换 | 控制流（流 0） |
| `PUSH_PROMISE` | 0x05 | 服务端承诺推送资源 | 父请求双向流（Server→Client） |
| `GOAWAY` | 0x07 | 优雅关闭通知 | 控制流 |
| `MAX_PUSH_ID` | 0x0D | 客户端允许的最大推送 ID | 客户端控制流（Client→Server） |

### Frame 编解码规则

**Varint 编码（RFC 9000 §16）**：

```
Length Range              Byte Format
─────────────────────────────────────────────
0x0000 - 0x003F          00xxxxxx     (1 byte)
0x0040 - 0x3FFF          01xxxxxx     (2 bytes)
0x4000 - 0x3FFFFF        10xxxxxx     (4 bytes)
0x400000 - 0x3FFFFFFF    11xxxxxx     (8 bytes)
```

**C++ 实现**：

```cpp
template <typename OutputStream>
void encode_varint(OutputStream& os, uint64_t value) {
    if (value <= 0x3F) {
        os.put(static_cast<uint8_t>(value));
    } else if (value <= 0x3FFF) {
        os.put(static_cast<uint8_t>(0x40 | (value >> 8)));
        os.put(static_cast<uint8_t>(value & 0xFF));
    } else if (value <= 0x3FFFFFFF) {
        os.put(static_cast<uint8_t>(0x80 | (value >> 24)));
        os.put(static_cast<uint8_t>((value >> 16) & 0xFF));
        os.put(static_cast<uint8_t>((value >> 8) & 0xFF));
        os.put(static_cast<uint8_t>(value & 0xFF));
    } else {
        os.put(static_cast<uint8_t>(0xC0 | ((value >> 56) & 0x3F)));
        os.put(static_cast<uint8_t>((value >> 48) & 0xFF));
        // ... 6 字节扩展
    }
}

// HEADERS frame 长度：QPACK 编码后字节数
size_t encode_headers_frame(const http_headers& headers) {
    auto encoded = qpack::encode(headers);
    encode_varint(stream_, 0x01);  // type
    encode_varint(stream_, encoded.size());  // length
    stream_.write(encoded);
    return encoded.size() + varint_size(0x01) + varint_size(encoded.size());
}

// DATA frame 可使用 span 直接引用
void encode_data_frame(std::span<const std::byte> payload) {
    encode_varint(stream_, 0x00);  // type
    encode_varint(stream_, payload.size());  // length
    stream_.write(payload);  // 直接写入原始字节，无拷贝
}
```

**解码器逻辑**：

```cpp
expected<http_frame, error_code> decode_frame(std::span<const std::byte>& buffer) {
    auto type = try_decode_varint(buffer);
    if (!type) {
        return unexpected(http3_errc::frame_too_short);
    }
    
    auto length = try_decode_varint(buffer);
    if (!length) {
        return unexpected(http3_errc::frame_too_short);
    }
    
    if (buffer.size() < *length) {
        return unexpected(http3_errc::insufficient_data);
    }
    
    std::span<const std::byte> payload = buffer.first(*length);
    buffer = buffer.subspan(*length);
    
    switch (*type) {
        case 0x00:
            return http_data_frame{payload};
        case 0x01:
            return http_headers_frame{qpack::decode(payload)};
        case 0x04:
            return http_settings_frame{decode_settings(payload)};
        // ... 其他帧类型
        default:
            return unexpected(http3_errc::unknown_frame_type);
    }
}
```

## Router 中间件集成示例

### 中间件链构建

```cpp
#include <cnetmod/protocol/http/middleware.hpp>

int main() {
    auto router = std::make_unique<cnetmod::http::router>();
    
    // 构建中间件链
    auto middleware_chain = cnetmod::http::middleware::chain<>();
    
    // 1. CORS 中间件
    middleware_chain.use(cnetmod::http::middleware::cors({
        .allowed_origins = {"https://example.com", "https://api.example.com"},
        .allowed_methods = {"GET", "POST", "PUT", "DELETE"},
        .allowed_headers = {"Content-Type", "Authorization"},
        .max_age = std::chrono::hours(24)
    }));
    
    // 2. 请求 ID 追踪
    middleware_chain.use(cnetmod::http::middleware::request_id({
        .header_name = "X-Request-ID",
        .generator = []() { return uuid::generate_v4(); }
    }));
    
    // 3. 访问日志
    middleware_chain.use(cnetmod::http::middleware::access_log({
        .format = "[%{timestamp}] %{method} %{path} %{status} %{latency_ms}ms",
        .output = cnetmod::logging::stdout_logger()
    }));
    
    // 4. 速率限制
    middleware_chain.use(cnetmod::http::middleware::rate_limit({
        .max_requests = 1000,
        .window = std::chrono::minutes(1),
        .by = cnetmod::http::middleware::rate_limit_by::ip_address
    }));
    
    // 将中间件应用到路由
    router->get("/api/*", [chain = middleware_chain](cnetmod::http::request_context& ctx) {
        return chain.process(ctx, [&]() {
            // Handler body
            auto resp = ctx.response();
            resp.set_status(200);
            resp.set_header("Content-Type", "application/json");
            resp.body() = R"({"result": "success", "data": []})";
        });
    });
    
    return 0;
}
```

### 自定义中间件

```cpp
class authentication_middleware : public cnetmod::http::middleware_interface {
public:
    auto process(cnetmod::http::request_context& ctx, 
                 cnetmod::http::handler_fn next) -> cnetmod::http::response {
        // 检查 Authorization 头部
        auto auth_header = ctx.request().header("Authorization");
        if (!auth_header) {
            return ctx.response().set_status(401).body("Unauthorized");
        }
        
        // 验证 JWT token
        auto token = auth_header.value().substr(7);  // "Bearer "
        auto [valid, claims] = jwt::verify(token, secret_key_);
        
        if (!valid) {
            return ctx.response().set_status(403).body("Forbidden");
        }
        
        // 注入用户信息到请求上下文
        ctx.set_attribute("user_id", claims["sub"]);
        ctx.set_attribute("user_role", claims["role"]);
        
        return next();
    }
    
private:
    std::string secret_key_;
};

// 使用
middleware_chain.use(std::make_unique<authentication_middleware>("my_secret"));
```

## HTTP/3 特有 API

### Server-side

**发送 GOAWAY 通知**：

```cpp
// 优雅关闭连接：通知客户端不再接受新流
task<void> graceful_shutdown(cnetmod::http::v3::http3_server& server,
                              cnetmod::http::stream_id last_stream) {
    // 发送 GOAWAY 帧
    co_await server.send_goaway(last_stream);
    
    // 等待活跃流完成（超时保护）
    auto deadline = std::chrono::steady_clock::now() + std::chrono::seconds(30);
    
    while (server.active_stream_count() > 0) {
        co_await std::chrono::milliseconds(100);
        if (std::chrono::steady_clock::now() > deadline) {
            // 超时：强制关闭
            server.force_close(cnetmod::quic_errc::no_error);
            break;
        }
    }
    
    // 最终关闭
    co_await server.close();
}

// 使用示例
void signal_handler(int sig) {
    cnetmod::spawn(*ctx, graceful_shutdown(server, server.last_stream_id()));
}
```

### Client-side

**连接池 API**：

```cpp
class http3_client_pool {
public:
    // 获取或创建连接
    cnetmod::http::v3::http3_client& get_or_create(
        const std::string& host, uint16_t port) {
        auto key = fmt::format("{}:{}", host, port);
        
        auto it = connections_.find(key);
        if (it != connections_.end() && it->second.is_connected()) {
            return it->second;
        }
        
        // 创建新连接
        auto [conn, _] = connections_.try_emplace(
            key, cnetmod::http::v3::http3_client(ctx_, ssl_ctx_, opts_));
        
        conn->second.connect(host, port).sync_wait();
        return conn->second;
    }
    
    // 关闭所有连接
    void close_all() {
        for (auto& [_, client] : connections_) {
            client.close().sync_wait();
        }
        connections_.clear();
    }
    
    // 连接健康检查
    bool is_connected(const std::string& host, uint16_t port) const {
        auto key = fmt::format("{}:{}", host, port);
        auto it = connections_.find(key);
        return it != connections_.end() && it->second.is_connected();
    }
    
private:
    std::unordered_map<std::string, cnetmod::http::v3::http3_client> connections_;
    cnetmod::io_context& ctx_;
    cnetmod::ssl_context& ssl_ctx_;
    cnetmod::http::v3::http3_client_options opts_;
};

// 使用示例
http3_client_pool pool(ctx, ssl_ctx);

auto& client1 = pool.get_or_create("api.example.com", 443);
auto& client2 = pool.get_or_create("api.example.com", 443);  // 复用连接

}
```

## 已知限制

### 当前版本

- ✅ **显式 Server Push**  
  默认关闭。客户端通过 `http3_client_options::max_push_id` 明确授权后，服务端可在
  `http3_response::pushes` 中声明资源；`PUSH_PROMISE` 会先于父响应 HEADERS 发送。
  推送响应支持静态 `body`，也支持带背压、trailers 与取消 token 的 `body_source`。
  客户端 `on_server_push` 仅在推送完整校验后调用。

- ✅ **Push 主动取消**  
  `http3_client_options::on_server_push_promise` 会在 Push body producer 启动前提供  
  `push_id` 与承诺请求。回调返回错误会自动发送 `CANCEL_PUSH`；也可以保存 ID 后调用  
  `http3_client::cancel_server_push(push_id)`。取消会停止客户端交付，并触发服务端  
  `body_source` 的 cancel token，不影响父响应和其他 Push。

- ✅ **支持 QPACK 动态表更新指令**  
  已实现 encoder/decoder 单向流、动态插入、动态索引、Required Insert Count
  阻塞恢复、确认和流取消。客户端默认启用 64 KiB 动态表与 100 个阻塞流。

- ⚠️ **GOAWAY 实现不完整**  
  仅支持基础通知功能，不自动等待活跃流完成。需应用层手动处理。

- ⚠️ **实验性 HTTP/3 WebTransport（已强制端到端验证）**  
  已支持 Extended CONNECT、HTTP Datagram、双向/单向子流前缀、按 session ID 分流、异步服务端 handler、子流读写以及携带应用错误码的 Close Capsule。CI 使用 aioquic 强制验证普通 H3 GET、Extended CONNECT、子流、DATAGRAM 与 Close Capsule；缺少 peer 会令门禁失败。两端必须启用 QUIC Datagram 和 Extended CONNECT；请使用 `webtransport_session` 收发 Datagram 与子流。

- ✅ **支持 QUIC 连接迁移**  
  收到新 UDP 源地址后会执行 PATH_CHALLENGE/PATH_RESPONSE 验证，验证成功后切换 peer endpoint 与可用 CID；HTTP/3 流无需重连即可继续。Windows Debug/Release 已有 UDP 源端口切换回归测试。
